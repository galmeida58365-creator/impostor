# Impostor

Jogo do impostor pra jogar com a galera passando um celular só.

- Configure jogadores, número de impostores, tipos de palavra, dica pro impostor e tempo de discussão
- Cada um arrasta a carta pra cima pra ver a palavra (ou descobrir que é o impostor)

## Baixar o APK
Vá em **Releases** (lado direito da página do repositório) e baixe o `Impostor.apk` mais recente.

O APK é gerado automaticamente pelo GitHub Actions a cada mudança na branch `main`.

## Mudar o jogo
O jogo todo está em `app/src/main/assets/index.html`. Edite, faça commit, e um APK novo sai sozinho.
